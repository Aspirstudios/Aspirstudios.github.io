Aspir Shell for Windows is now available for full use.

We're happy to announce that Aspir is now as useful as the original Windows GUI. Aspir now includes several hotkeys and built-in programs that make it easier and more convenient to use.

The new release of Aspir is so feature-rich that we are moving from installers to ZIP packages because of the large number of files included.

![Aspir Shell](https://blogger.googleusercontent.com/img/a/AVvXsEgKienUCwWODZBXG10mdb0NIYmh7i8Nz_nX8vOILss-cZXCDcqe9vW4hD1jgahbI3oKE54owlflvcCrk-VDojue-yotvasxznKY9cTY1spkGkvZSu8sQRUqbXWwAAXj4C7xx8DrvEJX3PR_akkWwMNX5xuUMAhwhF8sII8imyiHQSms3B4puhUuUa7gUOPR=w640-h360)

### Aspir now includes features such as:

- Run your own programs by simply placing their `.lnk` shortcuts inside the Aspir folder and typing their names in Aspir.
- Expanded control panel and power management options.
- A useful window manager that can be opened by pressing the Windows key.
- Launch programs by typing their provided names in the **Start a Program** option.
- Aspir completely replaces Windows Explorer.
- Theme support for the main applications (excluding the Window Manager and Start a Program utilities).
- Custom desktop background (type **c1** — see the configuration prefixes explained below — and select option 4 to set the background image path).

### Window Manager commands

Type `cmd`, `firefox`, or the name of any running program followed by:

- `bringtofront` — Brings the selected application to the front.
- `kill` — Closes the selected application.
- `bringtoback` — Sends the selected application to the back.

![Window Manager](https://blogger.googleusercontent.com/img/a/AVvXsEh54DQAT8FnZakBZrqWFo7ZlybSmgeiTxIoyPbapbIDFol7wogfkPOeu1p7KvyXJOpPe_6udEK6VsFsiGES2ajq7bpOYKZqBS6FTbtYT3Ca14IDtnmX5cegoJyj9GuNBiF_EuLLg8kA7j4-mThiknXZYStp64sEymq1ph1qKiY2MfZeshDp-TM0MB0BThb6=w640-h360)
